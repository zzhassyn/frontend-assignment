Midterm Project Specification

Project Topic: DevSphere — Student Developer Showcase Platform

DevSphere is a centralized web platform designed for software engineering students at Astana IT University. The target users are undergraduate students seeking portfolio recognition, peer collaborators looking to join ongoing coding builds, and faculty mentors monitoring capstone projects. The primary purpose of the website is to streamline student project discovery, provide an open repository for campus code showcases, and foster peer-to-peer recruitment across technical disciplines. By integrating detailed project portfolios, member skill matrices, and direct application workflows, DevSphere elevates student projects from isolated coursework into collaborative campus initiatives.
