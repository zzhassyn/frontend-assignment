Understanding CSS Float & Clear Properties

The float property was historically used to create multi-column website layouts before Flexbox and Grid existed. Floating an element moves it to the left or right edge of its parent container, allowing adjacent text to wrap around it.

By floating one block to the left (float: left) and another block to the right (float: right), we can create a two-column sidebar layout.

The Role of Clearfix (clear: both)

When elements are floated, they are removed from the normal document flow. Because of this, the parent container does not automatically detect their height and can collapse.

To fix this, we insert a divider element with clear: both; right after the floated columns, forcing the parent to encompass both columns.
